# v0.4.5 多媒体边界复查与修复

以 v0.4.4 为基准，四项风险均先通过隔离反例确认。保持不操作本机服务、不读写真实数据库、不重跑原文章、不发送微信、不修改/重试17条历史失败。原工作区修改和既有探针保留。

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 多附件仅链接第一份 | 已落盘文件缺少可追溯入口；特殊文件名也可能破坏Markdown链接 | 收集箱和灵感记录列出全部下载路径，按各自笔记目录计算相对路径，去重并分别转义链接标签/URL；兼容旧单路径参数 |
| 8000字符预览静默截断 | 模型及用户可能把文件开头当全文 | 保持预算，显式标出前8000/总UTF-16码元，提示进入模型、存档和回执；原始文件完整保存，本地CLI仍可另行读取 |

| 相同视频临时路径共用 | 并发ASR时一条处理清理了另一条仍在使用的文件 | 每次原生视频处理生成独立临时文件名，永久附件仍按内容去重 |

## 回归与兼容

- 收集箱/灵感两分支的全部附件链接可解析到真实fixture文件；覆盖中文、空格、括号、方括号等名字，旧单附件与新数组合并去重。
- 长文本预览提示在模型输入、笔记、回执均保留；7999/8000/8001边界验证仅截取时提示，原始文件逐字不变。
- CDN覆盖声明超限、实际超限、声明偏小、默认上限、空响应、断流、HTTP错误及取消错误；失败后没有半份存档。
- 不超限的分块加密/明文保持字节一致，重复下载保留同一路径；私网重定向被拒，非法limit在网络请求前拒绝。
- 两条同内容原生视频并发执行：前者归档清理后，后者仍可读取自己的临时文件；最终两份临时文件均清理。
- 首轮7项反例均失败，修复后主反例通过，再补兼容/失败矩阵；真实模型和微信均未调用。既有视频质量、17条合成历史failed保持及其他渠道测试在全量套件内运行。

验收结果：新增 **20项回归**；全量 **471通过、0失败、2211断言**（20个文件）；隔离审计 **7通过、40断言**，库/sidecar与环境哨兵均未变，裸测试及越界attach被拒。TypeScript 5.9.3、git diff --check通过，Spec/Standards复核无剩余阻断项。

## 尚存边界

128 MiB限制的是单份入站响应，不是进程内存上限；Buffer合并、解密和多附件会增加峰值。当前未改为全程流式解密/磁盘缓存，也没有改变文件/图片出站策略。

8000码元预览是有提示的摘取，不保证全文件语义理解。旧笔记不补写链接，未新增自动重试、补抓或模型调用。视频仍以口播转写为主，没有逐帧完整理解。真实平台登录、取流受限（例如YouTube403）、实际模型表现和手机排版仍需另行授权验收。
