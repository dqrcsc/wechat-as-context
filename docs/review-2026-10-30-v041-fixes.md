## 兼容与边界

- 严格身份核验优先避免错误归档。页面或 SEO 缺少作品标识时可能不再返回以前的 metadata 结果；已核验目标而无音频仍可明确降级为文案。没有从第一条记录、任意 DOM `<video>` 或未经绑定的网络流猜身份的后门。
- 作品对象匹配只能验证平台提供的标识与本次目标一致，不证明平台内容本身真实。社媒登录、反爬、真实 Chrome 冷启动与实际 ASR 未实机测试；本次未调用外部模型。
- “星期五”只在已经过去时顺延一周；“本周五/这星期五”已过会报错。重复周期仍需“每”。日期/时刻标签从最终时间生成。
- 名称不唯一或语言无法明确解析时，使用 #ID。路由模型 ID 仅是提示，不能代替用户原话的明确目标。取消/完成不再依靠删词后的近似名称；更保守的识别可能要求用户补充编号。
- `ScheduleRunRejected` 的 busy/not_executed 不创建稍后运行请求；需要再次执行时由用户明确发起。HTTP 返回结构化 code，busy/not_executed 为409，not_found 为404；失败/跳过 outcome 的 ok 为 false。CLI 手动繁忙/异常及失败 outcome 非零退出，无到期任务的空闲扫描仍成功返回空数组。
- 成功代表执行结果与回执已入队，不代表微信送达。本次不更改 outbox 重试策略，不重试历史失败，也不新增持久化手动执行队列。
- 无新增数据库 schema 迁移；已有笔记、push 历史文件约定、归档与故障恢复语义保持。ffmpeg/local-asr 异步化和固定 TypeScript 工具依赖是已记录的后续优化，本次未扩展实现。

## 验证方式

统一使用 `bun --no-env-file run test` 与 `bun --no-env-file run test:isolation`，入口复制源码至临时目录，隔离 HOME、数据库、配置、文件访问及出站网络。CLI 子进程继承隔离；HTTP 回归仅临时本地测试端口，不启动部署服务。

媒体抓取、转写和浏览器数据均采用合成夹具。原抖音短链测试补上真实 fetch 应携带的响应 URL，明确模拟重定向后的作品 ID；没有放松身份检查来迁就旧夹具。

- 全量：**334通过 / 0失败，1616断言**；较 v0.4.0 的236项新增98项，正式保留在两个 v041 测试文件中。
- 隔离审计：**7通过 / 0失败，39断言**；外部合成哨兵数据库及侧文件、项目/home配置不变，裸测试与越界 ATTACH 被拒绝。
- 类型检查：使用本机已缓存的 TypeScript 5.9.3 执行 `tsc -p tsconfig.json --noEmit` 通过；不将此等同于 `bun x tsc` 在线解析入口的本机验证。
- `git diff --check`、新增文档链接与全局技能模板一致性检查通过。全局技能项目路径保持不变。
- Standards / Spec 最终只读复核分别确认原反例关闭，在本次范围内未发现新的确定性阻断项。
