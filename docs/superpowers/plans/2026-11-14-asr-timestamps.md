# 本地 ASR 分段时间与覆盖校验

用户已授权实现、隔离验证和发布。沿用当前工作 checkout，原工作区及生产目录不写。

方案：仓库内Python适配器复用现有managed local-asr的Python环境和模型缓存，全文解码后的16kHz单声道WAV先完整VAD扫描，再对每个检测区间独立识别。时间来自音频样本/VAD，不从字数均摊；每区间记录ok/empty/failed。显式LOCAL_ASR_BIN仍优先，旧CLI无证据时继续partial；默认managed安装自动采用适配器，不修改全局工具。适配器只读取已存在模型，不下载、不联网。

complete仅表示完整解码且VAD扫描成功，合法区间逐一匹配、所有区间都取得文本，输入/解码时长在500ms容器边界容差内。静音不计漏转写；不保证VAD无漏检或逐字准确。未知/非法时间、空段、失败段、解码不完整均不得complete。证据和原文词语保存，不自动纠正专名。
