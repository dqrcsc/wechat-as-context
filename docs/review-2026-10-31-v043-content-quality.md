# v0.4.3 采集完整性与紧凑初筛修复

本版处理 v0.4.2 观察中发现的图集漏页、YouTube 降级归因、发布日期、超长初筛和正文噪声。不改发送队列策略，不自动重跑文章或改写历史文件；发布不等于本机部署。

## 行为与限制

| 优先级 | 问题 | 修复与验收边界 |
| --- | --- | --- |
| P1 | 9 页图集只读前 6 页 | 顺序按 6 页一批读取；按原页码校验非空 OCR 文本，重复/遗漏页均算未解析。最多尝试 60 页、单图 6 MiB，超过上限或下载失败明确列缺页。两平台同一契约。 |
| P2 | YouTube 音频 403 被写成作者未开放字幕 | 分开记录字幕未发现、字幕 HTTP/空响应、音频 HTTP/网络/流式失败、ASR 失败。未取得逐字稿时标记 metadata_only，不对源站可用性作推断。 |
| P2 | Medium 发布时间被采集日替代 | 采用可信 meta、当前文章 JSON-LD、文章 time 或 Medium 阅读时长旁的日期；Jina 只采用 Published Time；无证据留空并显示未知。采集时间另存 UTC。 |
| P2 | 手机初筛超长、无批注仍占栏目 | 移除无实质批注模块；渲染后超过 650 码点时最多追加一次压缩请求。业务/边界/分诊/实质批注须逐字保留，统计契约及伴读不变；不合格则保留全文、提示超长。 |
| P3 | 奖励区 UI、分享尾码、重复标点污染正文 | 只删除已识别 UI 行组成的奖励区尾缀；抖音时间尾码须匹配分享模板上下文；ASR 仅规范重复中文标点，原始文本转义后保留，不猜改专名和数字。 |

`complete` 指采集路径取得了逐页模型文本或逐字稿，不代表准确率、来源真实性或人工全文核验。OCR 模型可能错误识别；本版未使用真实文章或真实模型验证识别质量。发送成功也不意味着解析完整。

图集每批有最多 6 次图片获取和 1 次模型逻辑请求，批次数随页数增长；图片请求 15 秒、模型请求 45 秒超时。压缩只追加 1 次逻辑请求，既有 HTTP 瞬态重试可能产生额外网络尝试。条件无法在短版中完整放下时，明确超长优先于省略条件，不承诺任意内容一屏显示。

## 结构化质量与兼容

原文 frontmatter 新增可选内联 JSON `extraction_quality`，CLI `show <id> --json` 读取为 `extractionQuality`：

```json
{"status":"partial","reasons":["ocr_missing_or_invalid_page"],"totalPages":9,"processedPages":[1,2,3,4,5,6,7,9],"missingPages":[8]}
```

- 图集：`complete` / `partial` / `unavailable`，保留受控原因和页码；没有图片时为 `unavailable/no_images`。
- YouTube：取得逐字稿为 `complete`，否则为 `metadata_only`；先前字幕路径失败的原因可与最终成功并存。
- 旧文件没有该字段时返回 `null`，不默认为完整；旧 `transcript_engine: metadata_only` 可恢复降级状态，原因仅为 `legacy_reason_unknown`。
- 不合法 JSON、页码越界/重复/漏分配或 complete 与缺页矛盾时返回 `unavailable/invalid_saved_quality`。
- 原文恢复、初筛重分析和 CLI 查看均沿用保存的质量。分析及本地降级摘录携带缺失提示，伴读保留同样提示。
- 没有数据库迁移；已有 process_level / status / triage 不变。`done` 与质量状态是不同维度。
- 旧笔记不会补写新字段，旧日期不会自动纠正。普通 `reanalyze` 不等于补抓缺失图片；沿用已有 force 语义，不新增自动重试。

ASR 原始转写保存于带 `data-asr-raw="true"` 的 details/pre 块。正文使用标点清理结果并提示自动转写未核对；模型初筛剔除该原始保留块以免重复输入，但原文文件不删除。

## 回归矩阵

使用项目隔离测试入口，不读取真实 .env、数据库、私有业务快照；所有新增网络与模型交互均为 mock。

- 9 页/6+3 批、单页下载失败、模型漏页/重复页、无凭据、空图集、61 页上限、超大图、错误 MIME、模型 HTTP 错误、非法 JSON。
- 小红书与抖音图集分支到源文件落盘；页码和质量往返恢复。
- YouTube 字幕 HTTP 403、音频 HTTP 403、无字幕轨道、字幕成功、ASR 成功及原始转写保留。
- 流式下载断流、无 Content-Length 实际超限、过短流、abort、取消流失败时的阶段归因和不完整文件清理。
- meta / JSON-LD / time / Medium 日期、非法日期、未知日期、旁栏/其他文章日期和冲突来源；Jina 的存在/缺失日期。
- 保存的 partial 质量经过处理、重分析、CLI show，原文逐字不变；17 条合成失败记录逐字段不变，新增回执只入队且尝试次数为零。
- 空批注和仅链接标题、受限压缩成功、统计门槛/公式同文渲染、完整伴读保留；业务条件/边界/分诊变化、额外章节/前言、HTTP/JSON 错误或超长时保留原文。
- 正文引用奖励区并继续论述不误删；抖音真实附注与普通时间保留；ASR 专名、数值和原始文本保留。

复核额外发现并修复：奖励区匹配吞掉正文续文、压缩改变业务条件和可见分诊、下载断流误记为 ASR 失败。反例已纳入回归，不以提示词替代这些结构校验。
