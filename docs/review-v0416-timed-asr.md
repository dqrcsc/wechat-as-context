# v0.4.17：本地分段时间与覆盖校验

## 问题与成功标准

v0.4.16 正确停止了“非空即完整”的判断，但现有 local-asr 合并了 VAD 分段结果，无法提供逐段覆盖证据。此次补足真实时间来源、逐段结果、覆盖校验和保存回读；旧工具缺少证据时仍保守降级，不用字数推算时间，不猜改专名。

## 实现与边界

- 默认 managed local-asr 使用仓库 `scripts/local_asr_timed.py`，复用现有 Python 环境和 SenseVoice、fsmn VAD、CT 标点模型。独立完整解码 WAV，全音轨 VAD，再逐检测区间识别；不安装依赖、不下载模型，适配器禁止 Python 网络连接。显式 `LOCAL_ASR_BIN`、自定义安装或环境不完整时继续既有工具调用，不修改全局 CLI。
- `wxctx-vad-v1` 保存 `audioDurationMs`、`scanComplete`、`vadSegments` 和对应 `segments`。每段含毫秒 `startMs/endMs`、`ok/empty/failed`、原始文本。校验单位、顺序、非重叠、边界、数量、逐一对应和正文拼接一致性。时间来自音频/VAD，非字数分摊或逐字对齐。最多4小时、2000个区间，异常不静默丢段。
- `complete` 必须同时满足正常结束、完成全音轨扫描、检测到语音、每个区间取得非空文本、输入与解码时长差≤0.5秒、解码时长与 WAV 样本时长差≤20毫秒。VAD末尾10毫秒帧边界只允许裁到真实样本末尾。以上是编码/日志/帧精度容差，不是统计波动、模型置信度或准确率。
- `complete` 的准确含义是**本次 VAD 检测区间均已处理并取得文本**。不保证 VAD 无漏检、区间内每字都转出或专名正确；不将非检测区间直接认定为丢失。短语音区间缺上下文也可能错词。逐段时间供回听定位，不用于宣称逐字对齐。
- 空段或失败段保留位置并标 `asr_segments_missing`；所有段失败或无检测语音也不标完整。非法时间、扫描未完、缺时长或时长冲突分别降级。云端和旧工具无有效时间证据仍 `partial/asr_coverage_unverified`；既有 MAX_TOKENS 诊断保持兼容。
- 时间轴保存在原文折叠区，质量 JSON 中也保存对应文本和区间。抖音、小红书、YouTube直接/解析器兜底、微信原生视频/混合附件/灵感均传递；全空也保留时间失败证据。多视频通过 videoIndex 对应，已取得片段与完全缺失分开。YouTube 最终恢复后用 `initial_attempt_` 保存前次失败原因，避免误当当前质量。
- 专名/疑似错词候选继续保留原始 UTF-16 字符位置，不自动替换。新时间轴按语音区间定位，字符位置仍不冒充时间戳。模型提示明确上述边界，原有字幕/OCR采集逻辑不变。

FunASR 的独立 VAD 输出是起止毫秒区间，参见 [官方教程](https://github.com/modelscope/FunASR/blob/main/docs/tutorial/README.md)；本实现不把 SenseVoice 的文本输出伪装成原生逐字时间戳。
