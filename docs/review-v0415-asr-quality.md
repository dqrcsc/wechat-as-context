# v0.4.16：转写覆盖证据与疑似错词提示

## 已确认问题

v0.4.15 的公开 #80 音轨完整下载与解码成功，但本地 ASR 只返回一份无时间戳的合并文本。旧代码凭非空文本标记 complete；断句规则没有识别外文专名候选。取得完整音频、引擎结束、取得文本和逐字准确是不同事实，不能彼此代替。

## 修复与取舍

- 所有 ASR 返回先经过统一质量判定。非空本地结果及云端 STOP 均为 partial + asr_coverage_unverified；提示“已取得自动转写，完整性未核验”。这不是宣称已丢字。MAX_TOKENS 继续保留 asr_truncated，缺少结束状态继续保留 asr_finish_reason_missing；拒绝/空文本仍失败。
- 当前适配器不提供逐段时间覆盖证据，不用字数、时长相近或引擎退出0推断complete。未新增按固定切片强行推算覆盖率的逻辑，也不自动纠正原词。字幕/OCR采集规则不在本次变更范围。
- 新增 asrEvidence 数组：engineCompletion、textCharacters（Unicode码点）、timingAvailable=false，及可观测的 inputDurationSeconds、decodedDurationSeconds、segmentCount。缺失值省略。输入/解码秒数来自ffmpeg日志，段数来自本地JSON的segments，不等于带时间的语音分段。
- ffmpeg非零退出不采用残留WAV，保留asr_tool_ffmpeg_decode_failed，仍可用原媒体尝试原有引擎。无新增依赖、模型安装、超时扩张或云端请求。
- 证据随抖音、小红书、YouTube直接/yt-dlp音频兜底和微信原生视频归档。多视频带videoIndex；partialVideos包括已知片段与未核验覆盖的已转写视频。模型提示、微信质量提示、伴读及正文标题同步表达边界。非法证据、越界/重复视频索引或complete与未核验证据冲突时，读回明确降级。
- 中文语境最多列5处外文词/专名复核候选，去重并忽略常见缩写，纯外语正文不逐词提示；原有最多3处断句候选保留。所有位置均为原始UTF-16字符偏移，非音频时间戳。候选不代表已判错、不提供替换词；中文同音错词仍须听音，未列出不等于没有错误。
